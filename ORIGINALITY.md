# Originality and reference boundary

The repository was cloned because the assignment solution report explicitly
identified it as a structural reference. The submitted implementation and
corpus were then rebuilt independently.

- No text from the reference Drive folder is used in this project's raw,
  cleaned, train, validation, or test data.
- None of the reference corpus sources (Daily Express, Daily Jang, BBC Urdu,
  Makhzan, or CC-100) is used.
- The replacement sources are Urdu Wikipedia, Urdu Wikisource, and Urdu mC4.
- The normalizer, BPE implementation, collection scripts, cleaning pipeline,
  tests, analysis, figures, documentation, and report were independently
  authored for this version.
- Split seed `4172026`, ASCII digit convention, source-stratified splitting,
  provenance format, and analysis inputs differ from the reference solution.

The supplied solution artifacts were inspected only to understand the expected
deliverable structure and were then removed from the workspace. No pipeline
command or submitted dataset references them.
